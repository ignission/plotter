# Step 5: 土台（base）75° 版 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 75°（= 鉛直から 15° 後傾）の本体を支える土台を生成する。前部 4mm 平板 + 背部 28mm 厳部（傾斜上面）+ 前リップ + 5 本の角度付きホゾ穴を一体化した単一ソリッドの STL/STEP を出力できるようにする。

**Architecture:**
- `src/plotter/base.py` に `make_base(p: Params = default_params) -> Part`
- 構造: `Box(flat_front) + Wedge(ridge) - hole_box × 5`
- ホゾ穴は body 側のホゾ位置・断面に合わせて配置。本体が背厚部の傾斜上面に乗ったとき、ホゾが穴に正しく入る向き
- 60°/90° 版は将来対応（params の `panel_angle` でパラメータ化済み）。今回は 75° のみ

**Tech Stack:** build123d 0.10.0, pytest, Python 3.13

## 座標系と幾何

```
側面図 (X 軸方向から見る):

   Z↑
   │            ←  傾斜上面（前下がり 15°）
   │           ╱
 28│ ━━━━━━━━╱ Y=30 で Z=28
   │┃         ╲╲
   │┃           ╲╲ Y=50 で Z=28-20*tan(15°)=22.64
   │┃ flat front ┃
 4 ┝━━━━━━━━━━━━━━━━━━━━┓                  ┃
 7 │┃ ┃              ┃                       ┃
   │┃ ┃              ┃                       ┃
 0 ┕━┻━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛
   0  2             30              50  →Y
   ↑  
   前リップ (3mm 高×2mm 厚)
```

**部品リスト**:

1. **flat front** = `Box(panel_width, base_depth - base_ridge_depth, base_thickness)` at center (0, (base_depth - base_ridge_depth)/2, base_thickness/2) = (0, 15, 2)
2. **ridge** = 台形プロファイルの押し出し:
   - YZ 平面のスケッチ点 (Y, Z): (30, 0), (50, 0), (50, 28-20*tan(15°)), (30, 28)
   - X 方向に panel_width 押し出し
3. **front lip** = `Box(panel_width, base_front_lip_thickness, base_front_lip_height)` at (0, base_front_lip_thickness/2, base_thickness + base_front_lip_height/2) = (0, 1, 5.5)
4. **mortise hole × 5**: ridge から減算
   - 断面: (tenon_width + mortise_clearance) × (tenon_thickness + mortise_clearance) = 14.2 × 2.2mm
   - 深さ: tenon_height + 2 = 22mm（params に既存値はないのでファイル内定数 `MORTISE_DEPTH_MARGIN = 2.0` から計算）
   - 軸方向: world (0, -sin(angle_offset), -cos(angle_offset))
     ここで `angle_offset = 90° - panel_angle = 90 - 75 = 15°`
   - 穴の長手は body 側ホゾと同方向。15° 軸まわりの回転で「前下方向」に向ける
   - エントリ位置: 各ホゾの X 位置（body と同じ pitch 計算）、Y = `base_depth - base_ridge_depth/2` = 40、Z = 傾斜面 Z(40) = 28 - 10*tan(15°) ≈ 25.32

**ホゾ穴計算（angle_offset=15° 固定で確認済み）**:
- entry: (X, 40, 25.32)
- bottom: (X, 40 - 22*sin(15°), 25.32 - 22*cos(15°)) = (X, 34.31, 4.07)
- 穴下材厚: 4.07mm ✓
- 穴底〜ridge 前面材厚: 34.31 - 30 = 4.31mm ✓

**body との対応**:
ホゾ X 位置は body と同じ式: `pitch = (panel_width - tenon_width) / (tenon_count - 1)`、`x_i = -panel_width/2 + tenon_width/2 + i*pitch`

import math

import pytest
from build123d import Part

from plotter.base import make_base

def test_make_base_returns_part():
    """戻り値は build123d Part。"""
    base = make_base()
    assert isinstance(base, Part)


def test_base_outer_bbox_matches_params():
    """外形 bbox: X=panel_width, Y=base_depth, Z=base_ridge_height + 0（傾斜のため最大は ridge_height）。"""
    base = make_base()
    bbox = base.bounding_box()

    assert bbox.size.Z == pytest.approx(params.base_ridge_height, abs=0.01)

    """底面は Z=0 を起点とする（desk 接地）。"""
    base = make_base()
    bbox = base.bounding_box()
    assert bbox.min.Z == pytest.approx(0.0, abs=0.01)


def test_base_is_single_solid():
    """全パーツ（flat + ridge + lip - holes）が1つの連続したソリッド。"""
    base = make_base()
    assert len(base.solids()) == 1


def test_base_volume_is_positive_and_reasonable():
    """体積はゼロでなく、外接ボックスより小さい（傾斜と穴で削れている）。"""
    base = make_base()
    bbox = base.bounding_box()
    full_box_volume = bbox.size.X * bbox.size.Y * bbox.size.Z
    assert base.volume > 0
    assert base.volume < full_box_volume * 0.7  # 傾斜・穴で 30% 以上削れる


def test_base_mortise_clearance_meets_spec():
    """ホゾ穴のクリアランスは params.mortise_clearance (=0.2) を反映。

    実形状は穴を実体としてアサートできないので、設計上のクリアランス値が
    body 側のホゾ寸法に対して正しいかを params 経由で確認するメタテスト。
    """
    p = params
    hole_x = p.tenon_width + p.mortise_clearance
    hole_y_thickness = p.tenon_thickness + p.mortise_clearance
    assert hole_x == pytest.approx(14.2, abs=0.01)
    assert hole_y_thickness == pytest.approx(2.2, abs=0.01)

    """custom params で panel_width を変えると bbox の X も変わる。"""
    from dataclasses import replace
    custom = replace(params, panel_width=150.0)
    base = make_base(custom)
    assert base.bounding_box().size.X == pytest.approx(150.0, abs=0.01)

    ホゾ穴は angle_offset=15° で entry Z=base_ridge_height - (base_ridge_depth/2)*tan(15°)

    bottom_z = entry_z - 22.0 * math.cos(angle_offset)

```python
"""土台（base）の形状生成。

座標系:
- X: 幅方向 (panel_width=200)
- Y: 奥行方向 (Y=0 が前端、Y=base_depth が後端)
- Z: 高さ方向 (Z=0 が底面)

構造:
- 前部平板 (Y=0..base_depth-base_ridge_depth, Z=0..base_thickness)
- 背部厳部 (Y=base_depth-base_ridge_depth..base_depth、上面が前下がり 15° 傾斜)
- 前リップ (Y=0..base_front_lip_thickness, Z=base_thickness..base_thickness+base_front_lip_height)
- 角度付きホゾ穴 × tenon_count (背部厳部に貫通)

panel_angle (75°) から angle_offset = 90° - panel_angle = 15° を計算し、
ホゾ穴の axis を world (0, -sin(15°), -cos(15°)) に揃える。
"""

import math

from build123d import (
    Box,
    BuildPart,
    BuildSketch,
    Compound,
    Mode,
    Part,
    Plane,
    Polyline,
    Pos,
    Rot,
    extrude,
    make_face,
)

from plotter.params import Params
from plotter.params import params as default_params


def make_base(p: Params = default_params) -> Part:
    """土台を単一の Part として返す。"""
    flat_depth = p.base_depth - p.base_ridge_depth
    ridge_back_height = p.base_ridge_height - p.base_ridge_depth * math.tan(
        math.radians(90 - p.panel_angle)
    )

    # === flat front ===
    body = Pos(0, flat_depth / 2, p.base_thickness / 2) * Box(
        p.panel_width, flat_depth, p.base_thickness
    )

    # === ridge (台形プロファイルを X に押し出し) ===
    # YZ 平面で台形を描く: 4点 (Y, Z) = (flat_depth, 0), (base_depth, 0),
    # (base_depth, ridge_back_height), (flat_depth, ridge_height)
    with BuildSketch(Plane.YZ) as ridge_sketch:
        with BuildPart() as _ridge_solid:
            with BuildSketch(Plane.YZ):
                Polyline(
                    (flat_depth, 0),
                    (p.base_depth, 0),
                    (p.base_depth, ridge_back_height),
                    (flat_depth, p.base_ridge_height),
                    close=True,
                )
                make_face()
            extrude(amount=p.panel_width / 2, both=True)
        ridge = _ridge_solid.part
    body = body.fuse(ridge)

    # === front lip ===
    lip = Pos(
        0,
        p.base_front_lip_thickness / 2,
        p.base_thickness + p.base_front_lip_height / 2,
    ) * Box(p.panel_width, p.base_front_lip_thickness, p.base_front_lip_height)
    body = body.fuse(lip)

    # === mortise holes × tenon_count ===
    angle_offset_deg = 90 - p.panel_angle
    angle_offset_rad = math.radians(angle_offset_deg)
    hole_w = p.tenon_width + p.mortise_clearance
    hole_t = p.tenon_thickness + p.mortise_clearance
    hole_l = p.tenon_height + 2.0  # SPEC: depth = height + 2

    entry_y = p.base_depth - p.base_ridge_depth / 2
    entry_z = p.base_ridge_height - (p.base_ridge_depth / 2) * math.tan(angle_offset_rad)
    bottom_y = entry_y - hole_l * math.sin(angle_offset_rad)
    bottom_z = entry_z - hole_l * math.cos(angle_offset_rad)
    mid_y = (entry_y + bottom_y) / 2
    mid_z = (entry_z + bottom_z) / 2

    # ホゾ X 位置（body と同じ計算）
    if p.tenon_count == 1:
        x_centers = [0.0]
    else:
        pitch = (p.panel_width - p.tenon_width) / (p.tenon_count - 1)
        x_centers = [
            -p.panel_width / 2 + p.tenon_width / 2 + j * pitch
            for j in range(p.tenon_count)
        ]

    # 穴 Box: X=hole_w, Y=hole_t, Z=hole_l。これを X 軸まわりに 165° 回転すると
    # Z 方向（長手）が world (0, -sin(15°), -cos(15°)) に揃う。
    rotation_x_deg = 180 - angle_offset_deg  # 165° for 15°
    for x_c in x_centers:
        hole = Pos(x_c, mid_y, mid_z) * Rot(rotation_x_deg, 0, 0) * Box(
            hole_w, hole_t, hole_l
        )
        body = body.cut(hole)

    return Part(Compound([body]).wrapped)
```
