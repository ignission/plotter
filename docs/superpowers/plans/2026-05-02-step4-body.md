# Step 4: 本体パネル（body）実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 200×200×3mm の背板に 6 段の棚（仕切り＋リップ）と底端の 5 本のホゾを一体化した本体パネルを生成する。1/4 スケール試作（panel_width=100 / panel_height=80 / shelf_count=2 / tenon_count=3）とフルスケール本番（200×200 / 6棚 / 5ホゾ）の両方を出力できるようにする。

**Architecture:**
- `src/plotter/body.py` に純粋関数 `make_body(p: Params = default_params) -> Part` を実装。`p` から panel_*, shelf_*, tenon_* を読み取って一体ソリッドを返す
- 背板・仕切り×N・リップ×N・ホゾ×M を `+`（union）で連結し、単一の Part として STL/STEP 化可能にする
- 試作版は `dataclasses.replace(params, ...)` で寸法をオーバーライド（パッケージ側に「縮小モード」フラグを増やさない）
- ホゾ厚みは Z 中央配置（Z = 0.5〜2.5、3mm パネル内に2mm 厚を中心配置）

**Tech Stack:** build123d 0.10.0, pytest, Python 3.13

---

## 座標系と幾何モデル

```
Y (高さ)
↑
│
│ ┌───────────────┐
│ │   背板上部余白 (3mm)  │
│ ├───────────────┤
│ │   row 6 (slot=30.33mm) │
│ ├──── div6 (2mm) ────────┤
│ │   row 5                │
│ │   ...                  │
│ ├──── div1 (2mm) ────────┤
│ │   背板下部余白 (3mm)   │
│ └───────────────┘
│ │ホ│   │ホ│   │ホ│   │ホ│   │ホ│  ← Y < 0 にホゾ5本（X方向に等間隔）
│
└────────────────→ X (幅)

Z (奥行)
↑
│         ┌── lip (Z=panel_thickness+shelf_depth-shelf_lip_thickness 〜 panel_thickness+shelf_depth)
│         │
│  div ───┴───┐
│  ─────────────  ← 仕切り (Z=panel_thickness 〜 panel_thickness+shelf_depth)
│  ┌──────────┐
│  │ 背板 3mm │ (Z=0 〜 panel_thickness=3)
│  └──────────┘
└──────────────────→ Y
```

**寸法計算（フルスケール）:**

- panel_height = 200, panel_thickness = 3, shelf_count = 6, **shelf_divider_thickness = 1.5**（codex review で 2.0 から変更、SPEC 0.5mm クリアランス確保のため）
- 背板上下余白: 各 `panel_thickness` = 3mm
- 行高 + 仕切り の合計: `(panel_height - 2 * panel_thickness) / shelf_count` = (200 - 6) / 6 = 32.33mm
- 各行のカード収納スロット高さ: `row_pitch - shelf_divider_thickness` = 32.33 - 1.5 = 30.83mm（カード30mm + **0.83mm クリアランス**、SPEC 要求 0.5mm を上回る）

**仕切り i (i = 0..N-1) の Y 位置（下端）:**
`y_div_i = panel_thickness + i * row_pitch`

**リップ i は仕切り i の上に乗る:**
- リップ Y 範囲: `y_div_i + shelf_divider_thickness` から `+ shelf_lip_height`
- リップ Z 範囲: 仕切り前端から手前 `shelf_lip_thickness` mm（= `panel_thickness + shelf_depth - shelf_lip_thickness` 〜 `panel_thickness + shelf_depth`）

**ホゾ i (i = 0..M-1) の X 位置（中心）:**
`x_tenon_i = -panel_width/2 + tenon_width/2 + i * pitch`
ここで `pitch = (panel_width - tenon_width) / (tenon_count - 1)`（tenon_count >= 2 を仮定）

**ホゾの Y / Z 位置:**
- Y 範囲: `-tenon_height` 〜 `0`
- Z 範囲: `(panel_thickness - tenon_thickness) / 2` 〜 `(panel_thickness + tenon_thickness) / 2` = 0.5 〜 2.5（3mm 中の 2mm 厚を Z 中心）

"""body.make_body の形状検証テスト。"""

from dataclasses import replace

import pytest
from build123d import Part

from plotter.body import make_body
from plotter.params import params


def test_make_body_returns_part():
    """戻り値は build123d Part（Compound への緩和は許容しない）。"""
    body = make_body()
    assert isinstance(body, Part)


def test_full_body_outer_bbox_matches_panel_dimensions():
    """フルスケール本体の外形 bbox が想定値と一致すること。

    X: panel_width = 200
    Y: panel_height + tenon_height = 200 + 20 = 220 (ホゾが下に20mm伸びる)
    Z: panel_thickness + shelf_depth = 3 + 8 = 11
    """
    body = make_body()
    bbox = body.bounding_box()
    assert bbox.size.X == pytest.approx(params.panel_width, abs=0.01)
    assert bbox.size.Y == pytest.approx(
        params.panel_height + params.tenon_height, abs=0.01
    )
    assert bbox.size.Z == pytest.approx(
        params.panel_thickness + params.shelf_depth, abs=0.01
    )


def test_body_has_tenons_extending_below_panel():
    """ホゾはパネル底面 (Y=0) より下に tenon_height 分突き出していること。"""
    body = make_body()
    bbox = body.bounding_box()
    assert bbox.min.Y == pytest.approx(-params.tenon_height, abs=0.01)


def test_body_card_slot_clearance_meets_spec():
    """カード収納スロット高 = row_pitch - shelf_divider_thickness が
    card_height + 0.5mm 以上あること（SPEC 公差設計）。"""
    p = params
    row_pitch = (p.panel_height - 2 * p.panel_thickness) / p.shelf_count
    slot_height = row_pitch - p.shelf_divider_thickness
    assert slot_height >= p.card_height + 0.5


def test_body_tenon_centers_are_evenly_spaced():
    """ホゾの X 中心位置が等間隔ピッチ (panel_width - tenon_width) / (tenon_count - 1)
    で並ぶこと。X 方向の対称性も確認。

    幾何チェック: 5本のホゾがある場合、
    X = -93, -46.5, 0, +46.5, +93 を中心とするはず（panel_width=200, tenon_width=14）。
    bbox の X 範囲が [-100, +100] であることで panel_width との一致は別テストで確認済み。
    ここでは body.solids() を使わずホゾ位置の対称性を bbox から推測する代わりに
    実装依存の検証は避け、X 軸対称性のみ確認する。
    """
    body = make_body()
    bbox = body.bounding_box()
    # X 方向は左右対称（パネルもホゾも中央配置）
    assert bbox.min.X == pytest.approx(-params.panel_width / 2, abs=0.01)
    assert bbox.max.X == pytest.approx(params.panel_width / 2, abs=0.01)


def test_reduced_test_panel_bbox_and_slot():
    """縮小試作（panel_width=100, panel_height=80, shelf_count=2, tenon_count=3）の
    bbox とスロット高さ。"""
    test_params = replace(
        params,
        panel_width=100.0,
        panel_height=80.0,
        shelf_count=2,
        tenon_count=3,
    )
    body = make_body(test_params)
    bbox = body.bounding_box()
    assert bbox.size.X == pytest.approx(100.0, abs=0.01)
    assert bbox.size.Y == pytest.approx(80.0 + params.tenon_height, abs=0.01)
    # row_pitch = (80 - 6) / 2 = 37, slot = 37 - 1.5 = 35.5mm（カード余裕5.5mm）
    row_pitch = (80.0 - 2 * test_params.panel_thickness) / test_params.shelf_count
    slot = row_pitch - test_params.shelf_divider_thickness
    assert slot >= test_params.card_height + 0.5


def test_body_volume_is_positive_and_reasonable():
    """体積はゼロでなく、かつ「外接ボックスの中実」より十分小さい。"""
    body = make_body()
    full_box_volume = (
        params.panel_width
        * (params.panel_height + params.tenon_height)
        * (params.panel_thickness + params.shelf_depth)
    )
    assert body.volume > 0
    assert body.volume < full_box_volume * 0.5


def test_body_is_single_solid():
    """本体は1つの連続したソリッド（背板+仕切り+リップ+ホゾが全部連結）。

    建物が複数のばらばらの solid に分裂していたら STL として印刷不能。
    """
    body = make_body()
    assert len(body.solids()) == 1


def test_body_param_override_changes_geometry():
    """custom params で panel_width を変えると bbox も追従する。"""
    custom = replace(params, panel_width=150.0)
    body = make_body(custom)
    assert body.bounding_box().size.X == pytest.approx(150.0, abs=0.01)

```python
"""本体パネル（背板 + 棚 + リップ + ホゾ）の形状生成。

座標系:
- 原点: 背板下端中央、Z=0 が背板裏面
- X: 幅方向 (panel_width)
- Y: 高さ方向 (panel_height、Y=0 が背板下端、Y<0 にホゾが伸びる)
- Z: 奥行方向 (Z=0 が背板裏面、+Z 側に棚・リップが突き出る)
"""

from build123d import Box, Part, Pos

from plotter.params import Params
from plotter.params import params as default_params


def make_body(p: Params = default_params) -> Part:
    """本体パネルを単一の Part として返す。"""
    parts: list[Part] = []

    # === 背板 ===
    parts.append(
        Pos(0, p.panel_height / 2, p.panel_thickness / 2)
        * Box(p.panel_width, p.panel_height, p.panel_thickness)
    )

    # === 仕切り×shelf_count + リップ×shelf_count ===
    row_pitch = (p.panel_height - 2 * p.panel_thickness) / p.shelf_count
    shelf_front_z = p.panel_thickness + p.shelf_depth  # 棚前端の Z 位置
    for i in range(p.shelf_count):
        y_div_bottom = p.panel_thickness + i * row_pitch
        # 仕切り (横:panel_width, 厚:shelf_divider_thickness, 奥行:shelf_depth)
        parts.append(
            Pos(
                0,
                y_div_bottom + p.shelf_divider_thickness / 2,
                p.panel_thickness + p.shelf_depth / 2,
            )
            * Box(p.panel_width, p.shelf_divider_thickness, p.shelf_depth)
        )
        # リップ (横:panel_width, 高:shelf_lip_height, 厚:shelf_lip_thickness)
        # 仕切り上面に立ち、棚前端に寄せる
        parts.append(
            Pos(
                0,
                y_div_bottom + p.shelf_divider_thickness + p.shelf_lip_height / 2,
                shelf_front_z - p.shelf_lip_thickness / 2,
            )
            * Box(p.panel_width, p.shelf_lip_height, p.shelf_lip_thickness)
        )

    # === ホゾ×tenon_count（X 等間隔配置、Y<0 に突出、Z 中心配置）===
    if p.tenon_count >= 2:
        pitch = (p.panel_width - p.tenon_width) / (p.tenon_count - 1)
    else:
        pitch = 0.0
    for j in range(p.tenon_count):
        x_center = -p.panel_width / 2 + p.tenon_width / 2 + j * pitch
        parts.append(
            Pos(x_center, -p.tenon_height / 2, p.panel_thickness / 2)
            * Box(p.tenon_width, p.tenon_height, p.tenon_thickness)
        )

    # 全パーツを union（先頭から順に + で連結）
    body = parts[0]
    for piece in parts[1:]:
        body = body + piece
    return body
```

from build123d import export_step, export_stl

- build123d 0.10.0 で `Box + Box` の戻り値が `Part` か `Compound` か未確定。`test_body_is_single_solid` で `len(body.solids()) == 1` を厳格に見る。union 結果が複数 solid に分かれていた場合は形状が壊れている可能性 → BLOCKED で報告して実装を見直す（**戻り値型は緩めない**、codex 指摘）
- ホゾの Z 中心配置（0.5〜2.5）に確定。`base.py` 実装時はホゾ穴も同じ Z 中心データムを使うこと（背板裏面 Z=0 と揃える代替案は却下）
- ホゾ穴を持つ base.py との接続では、本体側ホゾ位置と土台側穴位置を「ホゾの X 等間隔」で合わせる必要がある。base.py 実装時に同じピッチ式 `(panel_width - tenon_width) / (tenon_count - 1)` を使うこと
- **大型平板の反りリスク**（SPEC.md 既知制約）: 200×200 のフルスケール印刷で PLA が反る可能性。実印刷時にブリム必須・接着剤推奨。`body_test.py` の縮小版で先に幾何検証してからフルへ進むのはこのリスクを下げる目的でもある
- shelf_divider_thickness を 1.5mm に減らした。仕切りの剛性は若干下がるが、片持ち長 8mm × 厚 1.5mm × 幅 200mm でも PLA インフィル25%なら撓み無視できる程度（試作で確認）
